## Role Summary

**Mission:** Expose enterprise capabilities to AI agents safely and consistently.

Builds Model Context Protocol (MCP) servers and tools — the secure, standardised connectors that let AI agents safely access systems and data.

## Key Responsibilities

- Design and build MCP servers, tools and resources.
- Define tool schemas, permissions and auth.
- Ensure safe, auditable agent access to systems.
- Document and version MCP interfaces.
- Test and harden MCP tools against misuse.

## Required Skills

### Technical Skills

- MCP specification, tools/resources/prompts.
- API design, auth and least-privilege.
- Schema design and validation.
- Security for agent-accessible tools.

### Business Skills

- Identifying which capabilities to expose to agents.

### AI Skills

- How agents discover and call tools; safe tool design.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- MCP SDKs
- TypeScript/Python
- OpenAPI
- Auth providers

## Certifications and Qualifications

- AIBOS MCP Engineering certification (Phase 17)

## Learning Path

1. Foundational: APIs, auth, JSON Schema.
2. Intermediate: MCP spec, tool design, security.
3. Advanced: enterprise MCP platforms and governance.

## Key Performance Indicators (KPIs)

- Tool reliability
- Auth/permission incidents
- Adoption by agents
- Spec coverage

## Typical Deliverables

- MCP servers
- Tool schemas
- MCP docs

## Collaboration and Interfaces

This role works most closely with: Agent Engineer, API Engineer, Security Engineer.

## Career Progression

1. **API/Backend Engineer**
2. **MCP Engineer**
3. **Senior**
4. **AI Platform Lead**

## Sample Interview Questions

1. How do you design a safe agent-callable tool?
2. How do you enforce least privilege in an MCP server?
3. How do you version MCP tools without breaking agents?
