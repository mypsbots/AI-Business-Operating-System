## Role Summary

**Mission:** Ship fast, accessible, maintainable user interfaces that match the design and delight users.

Builds the user-facing part of web/app products — the screens, interactions and state — with performance, accessibility and quality.

## Key Responsibilities

- Implement UI from designs using a modern framework.
- Manage client state, data fetching and error handling.
- Ensure accessibility, responsiveness and performance.
- Write unit/component/e2e tests.
- Integrate with backend and AI APIs.

## Required Skills

### Technical Skills

- JavaScript/TypeScript, React/Next.js (or Vue/Svelte).
- HTML, CSS, Tailwind and responsive design.
- State management, accessibility (WCAG), Core Web Vitals.
- Testing (Jest, Playwright) and build tooling.

### Business Skills

- Translating UX intent into product behaviour.

### AI Skills

- Consuming AI/LLM streaming APIs and building chat/agent UIs.
- Using AI coding assistants effectively and safely.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- React/Next.js
- TypeScript
- Tailwind
- Vite/Turbopack
- Playwright
- Storybook

## Certifications and Qualifications

- Framework/cloud front-end certs (optional)
- AIBOS Frontend Engineering certification (Phase 17)

## Learning Path

1. Foundational: HTML/CSS/JS, one framework, Git.
2. Intermediate: TypeScript, testing, accessibility, performance.
3. Advanced: AI-driven UIs, micro-frontends, design systems.

## Key Performance Indicators (KPIs)

- Core Web Vitals
- Accessibility score
- Defect rate
- Lead time

## Typical Deliverables

- Shipped UI features
- Reusable components
- Tests

## Collaboration and Interfaces

This role works most closely with: Product Designer, Backend/API Engineer, QA Engineer.

## Career Progression

1. **Junior**
2. **Engineer**
3. **Senior**
4. **Staff / Lead**

## Sample Interview Questions

1. How do you optimise Core Web Vitals?
2. How do you make a component accessible?
3. How would you build a streaming AI chat UI?
