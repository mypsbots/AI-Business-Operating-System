## Role Summary

**Mission:** Enable fast, reliable, automated delivery from commit to production.

Bridges development and operations by automating build, test and deployment pipelines so software ships frequently and safely.

## Key Responsibilities

- Build and maintain CI/CD pipelines.
- Automate testing, builds and deployments.
- Manage environments and release processes.
- Implement monitoring and rollback strategies.
- Improve delivery speed and reliability (DORA metrics).

## Required Skills

### Technical Skills

- CI/CD (GitHub Actions, GitLab CI, Jenkins).
- Containers, Kubernetes and IaC.
- Scripting (Bash/Python) and Git workflows.
- Monitoring and progressive delivery.

### Business Skills

- Reducing lead time and delivery risk.

### AI Skills

- Integrating AI test/code review and AI ops into pipelines.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- GitHub Actions
- Docker
- Kubernetes
- ArgoCD
- Terraform

## Certifications and Qualifications

- CKA
- Terraform Associate
- AIBOS DevOps certification (Phase 17)

## Learning Path

1. Foundational: Git, CI basics, containers.
2. Intermediate: Kubernetes, IaC, monitoring.
3. Advanced: progressive delivery, platform engineering.

## Key Performance Indicators (KPIs)

- Deployment frequency
- Lead time
- Change-failure rate
- MTTR

## Typical Deliverables

- CI/CD pipelines
- Deployment automation
- Runbooks

## Collaboration and Interfaces

This role works most closely with: Platform Engineer, SRE, Backend Engineer.

## Career Progression

1. **Engineer**
2. **DevOps Engineer**
3. **Senior**
4. **Platform/SRE Lead**

## Sample Interview Questions

1. Walk through a CI/CD pipeline you built.
2. How do you do zero-downtime deployments?
3. How do you roll back a bad release safely?
