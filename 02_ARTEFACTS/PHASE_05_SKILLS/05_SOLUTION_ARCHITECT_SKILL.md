## Role Summary

**Mission:** Translate requirements into a concrete, buildable, well-governed technical design.

Designs the technical solution for a specific product or project — components, integrations, data flow and non-functional requirements — within enterprise standards.

## Key Responsibilities

- Produce solution designs and component diagrams.
- Define APIs, data flows and integration points.
- Specify non-functional requirements (scale, security, cost).
- Guide engineering teams through implementation.
- Run design reviews and record decisions (ADRs).

## Required Skills

### Technical Skills

- System design and API/data modelling.
- Cloud services and integration patterns.
- Security and performance design.
- AI component design (RAG, agents) where relevant.

### Business Skills

- Requirements analysis
- Cost-aware design trade-offs

### AI Skills

- Designing AI-augmented solution components and guardrails.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- C4 diagrams
- OpenAPI
- Cloud consoles
- Draw.io / Miro

## Certifications and Qualifications

- Cloud associate/pro architect
- AIBOS Solution Architecture certification (Phase 17)

## Learning Path

1. Foundational: system design, APIs, cloud fundamentals.
2. Intermediate: integration patterns, NFRs, security design.
3. Advanced: AI solution architecture and trade-off analysis.

## Key Performance Indicators (KPIs)

- Design-review pass rate
- Delivery against NFRs
- Rework caused by design gaps

## Typical Deliverables

- Solution design docs
- API contracts
- ADRs
- Integration diagrams

## Collaboration and Interfaces

This role works most closely with: Enterprise Architect, Backend/API Engineers, Security Engineer.

## Career Progression

1. **Engineer**
2. **Senior Engineer**
3. **Solution Architect**
4. **Enterprise Architect**

## Sample Interview Questions

1. Design a solution for [scenario] and justify trade-offs.
2. How do you capture non-functional requirements?
3. How do you integrate an AI component safely?
