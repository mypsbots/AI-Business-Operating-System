## Role Summary

**Mission:** Get reliable, safe, cost-effective behaviour out of language models.

Designs, tests and maintains the prompts and instructions that steer LLMs — turning fuzzy requirements into reliable, safe model behaviour.

## Key Responsibilities

- Design and version prompts and system instructions.
- Build prompt templates and few-shot examples.
- Evaluate prompts for quality, safety and cost.
- Mitigate prompt injection and hallucination.
- Maintain a prompt library and guidelines.

## Required Skills

### Technical Skills

- Prompt patterns (few-shot, CoT, structured output).
- LLM parameters, context windows and tokenisation.
- Evaluation and A/B testing of prompts.
- Output parsing and function/tool calling.

### Business Skills

- Mapping business tasks to prompt designs.

### AI Skills

- Deep knowledge of LLM behaviour and limitations.
- Prompt-injection and jailbreak defence.
- Structured outputs and tool use.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- OpenAI/Anthropic APIs
- LangChain/LlamaIndex
- Prompt eval tools (Promptfoo)
- Playgrounds

## Certifications and Qualifications

- Vendor prompt courses
- AIBOS Prompt Engineering certification (Phase 17)

## Learning Path

1. Foundational: how LLMs work, basic prompting.
2. Intermediate: structured output, tool use, evaluation.
3. Advanced: prompt security, optimisation, agentic prompting.

## Key Performance Indicators (KPIs)

- Task success rate
- Hallucination rate
- Cost per task
- Eval pass rate

## Typical Deliverables

- Prompt templates
- Prompt library
- Eval reports

## Collaboration and Interfaces

This role works most closely with: LLM Engineer, RAG Engineer, AI Evaluation Engineer, Product Manager.

## Career Progression

1. **Prompt Engineer**
2. **Senior**
3. **AI Engineer**

## Sample Interview Questions

1. How do you make an LLM return reliable structured output?
2. How do you defend a prompt against injection?
3. How do you evaluate whether a prompt is 'good'?
