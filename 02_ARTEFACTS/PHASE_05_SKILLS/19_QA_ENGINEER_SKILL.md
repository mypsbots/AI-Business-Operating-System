## Role Summary

**Mission:** Ship software that works as intended, every time.

Ensures software quality through test design, automation and validation — catching defects before customers do.

## Key Responsibilities

- Design test plans, cases and acceptance criteria.
- Build automated test suites (unit/integration/e2e).
- Run functional, regression and exploratory testing.
- Report and track defects to closure.
- Integrate quality gates into CI/CD.

## Required Skills

### Technical Skills

- Test design and automation (Playwright, Cypress, pytest).
- API and contract testing.
- CI integration and test data management.

### Business Skills

- Risk-based test prioritisation.

### AI Skills

- Testing AI features (non-determinism, evals) and using AI test tools.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- Playwright/Cypress
- pytest/JUnit
- Postman
- TestRail

## Certifications and Qualifications

- ISTQB
- AIBOS QA certification (Phase 17)

## Learning Path

1. Foundational: test design, one automation framework.
2. Intermediate: API testing, CI integration, performance basics.
3. Advanced: testing AI systems and quality strategy.

## Key Performance Indicators (KPIs)

- Defect escape rate
- Automation coverage
- Test cycle time
- Flaky-test rate

## Typical Deliverables

- Test plans
- Automated suites
- Defect reports
- Quality gates

## Collaboration and Interfaces

This role works most closely with: Frontend/Backend Engineers, Product Manager, Performance Engineer.

## Career Progression

1. **QA Engineer**
2. **Senior QA**
3. **QA Lead / SDET**

## Sample Interview Questions

1. How do you decide what to automate vs. test manually?
2. How do you test a non-deterministic AI feature?
3. How do you reduce flaky tests?
