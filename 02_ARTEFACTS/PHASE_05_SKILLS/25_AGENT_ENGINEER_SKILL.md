## Role Summary

**Mission:** Deliver reliable agentic workflows that are safe and observable.

Builds autonomous and semi-autonomous AI agents that plan, use tools and complete multi-step tasks — with the right guardrails and human oversight.

## Key Responsibilities

- Design agent architectures (planning, tools, memory).
- Implement tool/function calling and orchestration.
- Add human-in-the-loop approval for risky actions.
- Build observability, evals and failure recovery.
- Manage multi-agent collaboration patterns.

## Required Skills

### Technical Skills

- Agent frameworks and orchestration.
- Tool/function calling, memory and planning.
- Guardrails, sandboxing and observability.
- MCP and external integrations.

### Business Skills

- Mapping business processes to agentic workflows.

### AI Skills

- Agentic patterns, autonomy boundaries, multi-agent coordination.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- LangGraph/CrewAI/AutoGen
- MCP
- Vector DBs
- Tracing (LangSmith)

## Certifications and Qualifications

- AIBOS Agent Engineering certification (Phase 17)

## Learning Path

1. Foundational: LLM APIs, tool calling, prompting.
2. Intermediate: agent frameworks, memory, evals.
3. Advanced: multi-agent systems, safety and autonomy design.

## Key Performance Indicators (KPIs)

- Task completion rate
- Human-intervention rate
- Cost per task
- Safety-incident rate

## Typical Deliverables

- Agent specifications
- Agent implementations
- Eval and trace dashboards

## Collaboration and Interfaces

This role works most closely with: MCP Engineer, LLM Engineer, AI Safety Engineer, Product Manager.

## Career Progression

1. **LLM Engineer**
2. **Agent Engineer**
3. **Senior**
4. **AI Architect**

## Sample Interview Questions

1. How do you decide what an agent may do autonomously?
2. How do you recover from a failed multi-step task?
3. How do you observe and debug an agent?
