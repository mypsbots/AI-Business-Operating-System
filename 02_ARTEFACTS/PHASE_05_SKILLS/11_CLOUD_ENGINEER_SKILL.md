## Role Summary

**Mission:** Provide secure, scalable, cost-effective cloud foundations.

Designs, provisions and operates cloud infrastructure (AWS/Azure/GCP) with a focus on reliability, security and cost efficiency.

## Key Responsibilities

- Provision cloud infrastructure via IaC.
- Design networking, identity and security on cloud.
- Optimise cost and right-size resources.
- Implement backups, HA and disaster recovery.
- Support workloads and troubleshoot cloud issues.

## Required Skills

### Technical Skills

- One major cloud (AWS/Azure/GCP) deeply.
- Networking, IAM, encryption, and well-architected design.
- Terraform/IaC and cost management.

### Business Skills

- Cloud cost optimisation (FinOps).

### AI Skills

- Provisioning GPU/model-hosting and AI services.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- AWS/Azure/GCP
- Terraform
- CloudWatch/Monitor
- Cost Explorer/FinOps tools

## Certifications and Qualifications

- AWS/Azure/GCP Associate→Pro
- AIBOS Cloud Engineering certification (Phase 17)

## Learning Path

1. Foundational: cloud core services, IAM, networking.
2. Intermediate: IaC, HA/DR, cost optimisation.
3. Advanced: multi-account/landing zones, AI infrastructure.

## Key Performance Indicators (KPIs)

- Infrastructure uptime
- Cloud cost vs. budget
- Security findings
- Provisioning lead time

## Typical Deliverables

- IaC modules
- Landing zones
- DR plans
- Cost reports

## Collaboration and Interfaces

This role works most closely with: Platform Engineer, SRE, Security Engineer.

## Career Progression

1. **Cloud Engineer**
2. **Senior**
3. **Cloud Architect**

## Sample Interview Questions

1. How do you design a secure multi-account cloud setup?
2. How do you cut cloud costs without hurting reliability?
3. How would you host an LLM workload?
