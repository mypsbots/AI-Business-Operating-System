## Role Summary

**Mission:** Ship robust, scalable, cost-efficient LLM-powered applications.

Builds production applications powered by large language models — integrating, fine-tuning, serving and optimising them reliably and safely.

## Key Responsibilities

- Integrate LLM APIs and self-hosted models into apps.
- Implement fine-tuning, function calling and structured output.
- Optimise latency, cost and reliability (caching, routing).
- Add guardrails, evaluation and observability.
- Manage model selection and versioning.

## Required Skills

### Technical Skills

- LLM APIs, fine-tuning and serving (vLLM, TGI).
- Function/tool calling, structured output, streaming.
- Cost/latency optimisation and model routing.
- Python and ML fundamentals.

### Business Skills

- Cost modelling of LLM features.

### AI Skills

- Model capabilities/limits across providers.
- Guardrails, evals and responsible AI.
- RAG and agent integration.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- OpenAI/Anthropic/Bedrock
- vLLM/Ollama
- LangChain
- Vector DBs
- Weights & Biases

## Certifications and Qualifications

- Cloud ML certs
- AIBOS LLM Engineering certification (Phase 17)

## Learning Path

1. Foundational: Python, LLM APIs, prompting.
2. Intermediate: RAG, fine-tuning, evaluation, serving.
3. Advanced: optimisation, multi-model routing, self-hosting.

## Key Performance Indicators (KPIs)

- Quality/eval scores
- p95 latency
- Cost per request
- Incident rate

## Typical Deliverables

- LLM services
- Eval harnesses
- Model cards

## Collaboration and Interfaces

This role works most closely with: Prompt Engineer, RAG Engineer, Backend Engineer, AI Safety Engineer.

## Career Progression

1. **ML/Backend Engineer**
2. **LLM Engineer**
3. **Senior**
4. **AI Architect**

## Sample Interview Questions

1. How do you choose between fine-tuning and RAG?
2. How do you reduce LLM cost in production?
3. How do you add guardrails to an LLM service?
