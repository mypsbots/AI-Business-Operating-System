## Role Summary

**Mission:** Deliver reliable, secure, performant services and data models.

Builds the server-side logic, data storage and business rules that power the product, with a focus on correctness, security and scale.

## Key Responsibilities

- Design and build services, business logic and data models.
- Write and optimise database queries and migrations.
- Implement authentication, authorisation and validation.
- Ensure observability, error handling and tests.
- Expose and consume APIs and events.

## Required Skills

### Technical Skills

- A server language (Python, Node/TypeScript, Go, Java).
- Relational + NoSQL data modelling and SQL.
- Caching, queues and event-driven patterns.
- Security (authz/authn, OWASP) and testing.

### Business Skills

- Translating domain rules into services.

### AI Skills

- Integrating LLMs/RAG into backend services with guardrails.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- PostgreSQL
- Redis
- Docker
- REST/gRPC
- Kafka/SQS
- OpenTelemetry

## Certifications and Qualifications

- Cloud associate
- Database certs
- AIBOS Backend Engineering certification (Phase 17)

## Learning Path

1. Foundational: one language, SQL, HTTP/REST, Git.
2. Intermediate: data modelling, caching, security, testing.
3. Advanced: distributed systems, event-driven and AI back ends.

## Key Performance Indicators (KPIs)

- Service availability
- p95 latency
- Defect/escape rate
- Test coverage

## Typical Deliverables

- Services and APIs
- Schema/migrations
- Tests and runbooks

## Collaboration and Interfaces

This role works most closely with: API Engineer, Frontend Engineer, Data Engineer, SRE.

## Career Progression

1. **Junior**
2. **Engineer**
3. **Senior**
4. **Staff / Lead**

## Sample Interview Questions

1. How would you design the data model for [scenario]?
2. How do you secure an endpoint end-to-end?
3. How do you add an LLM call without hurting reliability?
