## Role Summary

**Mission:** Deliver trustworthy, timely, well-modelled data at scale.

Builds the pipelines and platforms that move, clean and store data reliably — the foundation for analytics, ML and AI.

## Key Responsibilities

- Build batch and streaming data pipelines (ETL/ELT).
- Model and maintain data warehouses/lakehouses.
- Ensure data quality, lineage and governance.
- Optimise storage, cost and performance.
- Serve data to analytics, ML and AI teams.

## Required Skills

### Technical Skills

- SQL, Python and data modelling.
- ETL/ELT (dbt, Airflow), streaming (Kafka).
- Warehouses/lakehouses (Snowflake, BigQuery, Databricks).
- Data quality and lineage.

### Business Skills

- Aligning data models to business questions.

### AI Skills

- Preparing data for RAG/ML; vector and embedding pipelines.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- dbt
- Airflow
- Snowflake/BigQuery
- Kafka
- Spark

## Certifications and Qualifications

- Snowflake/Databricks/GCP data certs
- AIBOS Data Engineering certification (Phase 17)

## Learning Path

1. Foundational: SQL, Python, data modelling.
2. Intermediate: ETL/ELT, warehousing, orchestration.
3. Advanced: streaming, lakehouse, data platform design.

## Key Performance Indicators (KPIs)

- Pipeline reliability
- Data freshness
- Data-quality score
- Cost per TB

## Typical Deliverables

- Data pipelines
- Data models
- Quality checks

## Collaboration and Interfaces

This role works most closely with: Analytics Engineer, Data Scientist, RAG Engineer.

## Career Progression

1. **Engineer**
2. **Data Engineer**
3. **Senior**
4. **Data Architect**

## Sample Interview Questions

1. Design an ETL pipeline for [scenario].
2. How do you ensure data quality?
3. How do you prepare data for a RAG system?
