## Role Summary

**Mission:** Turn raw data into reliable, well-defined metrics and datasets.

Sits between data engineering and analysis — transforms raw data into clean, tested, documented models that the business can trust and self-serve.

## Key Responsibilities

- Build transformation models (dbt) with tests.
- Define and document metrics and a semantic layer.
- Ensure data quality and consistency.
- Enable self-serve analytics for the business.
- Maintain data documentation and lineage.

## Required Skills

### Technical Skills

- Advanced SQL and dbt.
- Dimensional modelling and metrics layers.
- Data testing and documentation.

### Business Skills

- Defining metrics that match business definitions.

### AI Skills

- Enabling natural-language analytics on top of clean models.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- dbt
- Snowflake/BigQuery
- Looker/dbt Semantic Layer
- Git

## Certifications and Qualifications

- dbt certification
- AIBOS Analytics certification (Phase 17)

## Learning Path

1. Foundational: SQL, data modelling.
2. Intermediate: dbt, testing, metrics layers.
3. Advanced: semantic layers and analytics platforms.

## Key Performance Indicators (KPIs)

- Metric consistency
- Model test coverage
- Self-serve adoption
- Time-to-insight

## Typical Deliverables

- dbt models
- Metric definitions
- Documentation

## Collaboration and Interfaces

This role works most closely with: Data Engineer, BI Analyst, Product Manager.

## Career Progression

1. **Analyst**
2. **Analytics Engineer**
3. **Senior**
4. **Analytics Lead**

## Sample Interview Questions

1. How do you ensure two teams compute 'revenue' the same way?
2. How do you test a data model?
3. How do you design a semantic layer?
