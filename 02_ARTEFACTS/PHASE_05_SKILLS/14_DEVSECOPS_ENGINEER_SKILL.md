## Role Summary

**Mission:** Make security automatic, continuous and developer-friendly.

Embeds security into the delivery pipeline — 'shift left' — so vulnerabilities are caught early and software supply chains are secure.

## Key Responsibilities

- Integrate SAST/DAST/SCA scanning into CI/CD.
- Manage secrets, SBOMs and supply-chain security.
- Define and enforce policy as code.
- Triage and remediate vulnerabilities with teams.
- Automate compliance evidence collection.

## Required Skills

### Technical Skills

- Application and pipeline security; OWASP ASVS.
- Secrets management and supply-chain security (SLSA, SBOM).
- Policy as code (OPA) and security automation.

### Business Skills

- Balancing security with delivery speed.

### AI Skills

- Securing AI pipelines and applying the OWASP LLM Top 10.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- Snyk/Trivy
- OWASP ZAP
- Vault
- OPA
- GitHub Advanced Security

## Certifications and Qualifications

- Security+
- CSSLP
- AIBOS DevSecOps certification (Phase 17)

## Learning Path

1. Foundational: AppSec basics, OWASP Top 10, CI/CD.
2. Intermediate: SAST/DAST/SCA, secrets, policy as code.
3. Advanced: supply-chain security and AI security.

## Key Performance Indicators (KPIs)

- Mean time to remediate
- Vulns escaped to prod
- Pipeline security coverage
- Secrets incidents

## Typical Deliverables

- Secure pipelines
- SBOMs
- Policy-as-code
- Remediation reports

## Collaboration and Interfaces

This role works most closely with: DevOps Engineer, Security Engineer, Compliance Specialist.

## Career Progression

1. **DevOps/Security Engineer**
2. **DevSecOps Engineer**
3. **Senior**
4. **Security Architect**

## Sample Interview Questions

1. How do you shift security left without slowing teams?
2. How do you secure a software supply chain?
3. How do you handle the OWASP LLM Top 10 in CI?
