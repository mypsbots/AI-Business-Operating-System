## Role Summary

**Mission:** Turn data into reliable, monitored predictive models in production.

Builds, trains and deploys machine-learning models (beyond LLMs) into production — owning the full ML lifecycle and MLOps.

## Key Responsibilities

- Build feature pipelines and train models.
- Deploy and serve models with monitoring.
- Manage experiments, versioning and MLOps.
- Detect and address drift and degradation.
- Optimise model performance and cost.

## Required Skills

### Technical Skills

- ML algorithms, feature engineering, evaluation.
- Python, scikit-learn, PyTorch/TensorFlow.
- MLOps: pipelines, registries, monitoring.

### Business Skills

- Framing problems as ML tasks with clear metrics.

### AI Skills

- Integrating classic ML with LLM/GenAI systems.

### Soft Skills

- Clear written and verbal communication with technical and non-technical people.
- Structured problem solving and evidence-based decision making.
- Collaboration across human teammates and AI agents.
- Ownership, reliability and a continuous-learning mindset.

## Tools and Technologies

- PyTorch/TensorFlow
- MLflow
- Kubeflow/SageMaker
- Feature stores

## Certifications and Qualifications

- Cloud ML Engineer certs
- AIBOS ML Engineering certification (Phase 17)

## Learning Path

1. Foundational: Python, statistics, ML basics.
2. Intermediate: feature engineering, model serving, MLOps.
3. Advanced: scalable ML platforms and GenAI integration.

## Key Performance Indicators (KPIs)

- Model accuracy/AUC
- Drift incidents
- Serving latency
- Time-to-deploy

## Typical Deliverables

- Trained models
- Pipelines
- Model cards
- Monitoring

## Collaboration and Interfaces

This role works most closely with: Data Scientist, Data Engineer, Backend Engineer.

## Career Progression

1. **Data Scientist/Engineer**
2. **ML Engineer**
3. **Senior**
4. **ML Architect**

## Sample Interview Questions

1. How do you deploy and monitor a model in production?
2. How do you detect and handle model drift?
3. How do you decide ML vs. LLM for a problem?
