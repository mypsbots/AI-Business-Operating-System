
# AIBOS_REFERENCE_STANDARDS.md

# AIBOS Enterprise v2.0
## Enterprise Reference Standards

Version: 2.0.0

---

# Purpose

This document is the authoritative catalogue of external standards, frameworks,
best practices and reference models adopted by AIBOS Enterprise.

It provides a single mapping layer between AIBOS and recognised industry
standards to improve governance, interoperability, security and enterprise
credibility.

---

# Objectives

- Standardise external references
- Avoid conflicting guidance
- Improve compliance readiness
- Enable consistent architecture decisions
- Support enterprise audits

---

# Adoption Principles

Every external standard should be:

- Evaluated
- Approved
- Version tracked
- Mapped to AIBOS artefacts
- Reviewed periodically

---

# Standards Mapping Template

Each adopted standard should record:

- Standard Name
- Version
- Publisher
- Scope
- Business Value
- Applicable Domains
- Related AIBOS Documents
- Compliance Requirements
- Implementation Guidance
- Review Frequency

---

# Governance

Architecture Governance Board responsibilities:

- Approve standards
- Review revisions
- Retire obsolete references
- Maintain compatibility mappings

---

# Compliance Matrix

Every AIBOS artefact should identify applicable standards within its metadata.

Examples:

- Security → ISO 27001, OWASP
- AI → ISO 42001, NIST AI RMF
- APIs → OpenAPI, OAuth 2.1
- Accessibility → WCAG 2.2 AA

---

# Review Cycle

- Quarterly review of emerging standards
- Annual baseline update
- Immediate review for critical security guidance
