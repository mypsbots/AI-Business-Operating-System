# Purpose

The AIBOS Enterprise Glossary is the canonical dictionary for every document,
AI agent, SDK, CLI, API, template, playbook, checklist, rule, skill,
knowledge article and automation within AIBOS.

Every document generated throughout AIBOS MUST use the terminology defined here.

---

# Objectives

- Establish one consistent enterprise vocabulary.
- Remove ambiguity.
- Improve AI retrieval (RAG).
- Improve semantic search.
- Improve agent memory.
- Improve documentation quality.
- Standardise naming.
- Enable enterprise governance.

# Example Entry

## TERM-000001

Canonical Term:
AI Agent

Category:
Artificial Intelligence

Definition:
An autonomous or semi-autonomous software component that performs tasks,
uses tools, reasons over context and collaborates with humans or other agents.

Business Context:
Automates business processes.

Technical Context:
LLM-powered orchestration component.

Purpose:
Increase productivity while maintaining governance.

Examples:

- Customer Support Agent
- Code Review Agent
- Sales Agent

- Hard-coded workflow

Artificial Intelligence

# Naming Rules

- One canonical term only.
- Avoid abbreviations unless industry standard.
- Acronyms must also have expanded definitions.
- Use British English.
- Keep definitions technology-neutral where possible.

---

# Cross-Reference Rules

Every new document should reference glossary terms instead of redefining them.

---

# Maintenance Policy

- Every new enterprise concept must first be added here.
- Deprecated terms remain for historical compatibility.
- Semantic versioning applies.
- Changes require governance review.
